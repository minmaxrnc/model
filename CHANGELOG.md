# Changelog

## 0.4.0

Backward compatible with 0.3.0: with default settings, models have the same
API, parameter names, seeded initial weights, outputs and recurrent states as
in 0.3.0, and 0.3.0 checkpoints load with `strict=True`. See
[Upgrading from 0.3.0](README.md#upgrading-from-030).

### Added

- **Matrix MinMax neurons.** `MinMaxRNCConfig.matrix_neurons` adds groups of
  full-matrix neurons, `x_{t+1} = max(R_t ⊗ x_t, s_t)` in the (max,min)
  semiring, to every layer, alongside or instead of the diagonal neuron.
  Each group is a `MatrixNeuronGroup(d_state, num_neurons=1, n_h=0,
  normalize_keys=False)` or an equivalent tuple/list, and runs as one batched
  parallel scan.
  - New modules `MatrixMinMaxNeuron` / `MatrixMinMaxNeuronConfig`.
  - New operator/scan functions `minmax_operator.apply_matrix`,
    `minmax_operator.compose_matrix`,
    `minmax_scan.all_composition_prefixes_matrix`,
    `minmax_scan.all_states_matrix`.
  - A `UserWarning` is raised for groups with `d_state=1` (scalar-state
    neurons, equivalent to diagonal ones).
  - `n_h > 0` (R_t as a product of rank-1 corrections to the identity,
    DeltaProduct-style) is **experimental**.
- **Scan precision.** `MinMaxRNCConfig.scan_dtype`: `'ambient'` (default,
  0.3.0 behaviour), or `'fp32'`, `'bf16'`, `'fp16'` to pin the scan's
  precision regardless of any autocast. With a pinned dtype the recurrent
  state is carried in that dtype.
- **Model-level mixed precision.** `MinMaxRNCConfig.amp_dtype`: `None`
  (default, the caller controls autocast as before), `'bf16'` or `'fp16'` to
  run `forward()` under `torch.autocast` (for the LM wrapper including the
  embedding and LM head).
- `MinMaxRNCConfig.num_neurons_per_layer` property.
- `MinMaxNeuronConfig.scan_dtype` and `MinMaxNeuronConfig._num_neurons_in_layer`
  (appended fields; defaults reproduce 0.3.0).
- `MinMaxLayerConfig.matrix_neurons` (appended field; default `()`).
- Package exports: `MatrixNeuronGroup`, `MinMaxNeuron`, `MinMaxNeuronConfig`,
  `MatrixMinMaxNeuron`, `MatrixMinMaxNeuronConfig`, `ScanDtype`, `AmpDtype`,
  `__version__`.
- Tests: `tests/test_backward_compat.py` checks 0.4.0 against reference values
  recorded with 0.3.0 (`tests/fixtures/v0_3_0_reference.pt`, regenerated by
  `tests/fixtures/make_v0_3_0_reference.py`); `tests/test_matrix_neurons.py`;
  `tests/test_precision.py`.
- Docs: README sections on matrix neurons, mixed precision and upgrading;
  `docs/model.md` sections on the matrix recurrence and numerical precision.

### Changed

- `MinMaxRNCConfig.d_state` now defaults to `0` (no diagonal neuron). Configs
  that set it behave exactly as before; leaving it out without
  `matrix_neurons` now raises `ValueError` (0.3.0 raised `TypeError`).
- `MinMaxLayerConfig.neuron` may be `None` (a layer with only matrix neurons).
- The per-layer recurrent state gains a `'matrix_neurons'` entry only for
  models with matrix neurons, and has no `'neuron'` entry when `d_state=0`;
  diagonal-only models keep exactly the 0.3.0 structure.
- Invalid `scan_dtype` / `amp_dtype` values raise `ValueError`.
